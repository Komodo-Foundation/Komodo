# zlib

zlib through `zlib.h`. Generated by `km-bind --auto zlib`, with no changes.

It covers the checksums (`crc32`, `adler32`) and `zlibVersion`. Compression is
not practical from Komodo yet: `compress` and `deflate` write raw bytes into
caller memory, and `z_stream` is an opaque handle that Komodo cannot allocate.
Use the checksums, or call the library from a small C shim.

Install the library with `sudo apt install zlib1g-dev`. Run the example with
`komodo bindings/zlib/example.km`.
