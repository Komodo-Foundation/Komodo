# pcre2

PCRE2, 8-bit code units. Generated by:

```bash
tools/km-bind /usr/include/pcre2.h -p libpcre2-8 -D PCRE2_CODE_UNIT_WIDTH=8 -m pcre2 -o pcre2.kmm
```

The 8-bit functions carry an `_8` suffix (`pcre2_compile_8`). The NULL context
and match-data handles cannot be passed from Komodo, so `km_pcre2_compile` and
`km_pcre2_matches` (`pcre2_handles.c`) do that work in C.

Install the library with `sudo apt install libpcre2-dev`. Run the example with
`komodo bindings/pcre2/example.km`.
