# sqlite3

SQLite 3 through `sqlite3.h`. Generated by `km-bind --auto sqlite3`, with one
hand-written section at the end of `sqlite3.kmm`.

`sqlite3_open` and `sqlite3_prepare_v2` return their handle through an
out-parameter, which a Komodo binding cannot use as a handle type. Use
`km_sqlite3_open` and `km_sqlite3_prepare` instead (`sqlite3_handles.c`).

```km
import sqlite3

void main()
    let db = sqlite3::km_sqlite3_open(":memory:")
    sqlite3::sqlite3_exec(db, "CREATE TABLE t(name TEXT, n INTEGER)", 0, 0, 0)
    ...
```

Install the library with `sudo apt install libsqlite3-dev`. Run the example with
`komodo bindings/sqlite3/example.km`.

Other functions are bound as generated. Variadic (`sqlite3_vmprintf`) and
`va_list` functions are skipped. Result codes come back as plain ints
(`100` is `SQLITE_ROW`).
