Modules

File Types

  • .km — program file (must contain a void main())
  • .kmm — module file (library code, no main)

Declaring a Module

Every module file starts with a module declaration:

module math

fn square(x: int): int
    return x * x

fn cube(x: int): int
    return x * x * x

This file is math.kmm. All files declaring the same module name are merged into one namespace.

Importing

Import modules with the import statement:

import math
import console

void main()
    let result = math::square(5)
    print(result)

The compiler searches for math.kmm in the project directory tree and compiles it together with your program. All imported modules are compiled as a single unit.

Namespacing

Access imported members using :: (scope) or . (member access):

import math

let x = math::square(5)      // module::member
let y = x.toString()         // receiver.method

After modules are merged, all members are in a flat namespace, so math::member resolves to member.

Built-in Modules

Some modules don't have source files — they're linked from C. Import them normally:

import console
import math
import algorithm
import file

These are resolved by the linker to their corresponding .c implementations.

Module Organization

Keep modules focused and cohesive. Good module structure:

// utils/math.kmm
module math

fn abs(x: int): int
    if x < 0
        return -x
    return x

// utils/string.kmm
module string

fn reverse(s: string): string
    // ...

// main.km
import utils::math
import utils::string

void main()
    print(math::abs(-5))

Entry Point

Your program file (.km) must define void main() or void main(args):

void main()
    print("Hello")

// Or with command-line arguments:
void main(args: [string])
    print("Arg count: ", #args)
    if #args > 0
        print("First arg: ", args[0])

Arguments start at index 0 (program name is at index 0, user args at 1+).
