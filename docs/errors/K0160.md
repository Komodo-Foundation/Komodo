# K0160: unreachable code

Message: `unreachable code`

## What went wrong

The statement follows a `return`, `break`, `continue` or `throw`, so it can never run. It is usually a leftover or a mistake.

**How to fix it:** Delete it, or move it before the jump.

## Example

<!-- doc-skip -->
Compile with `komodo --strict`.

```km
fn f(): int
    return 1
    console.print("never")

void main()
    console.print(f())
```

## Fixed

<!-- doc-skip -->
```km
fn f(): int
    console.print("before")
    return 1

void main()
    console.print(f())
```
