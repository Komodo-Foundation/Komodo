# K0141: unrelated pattern type

Message: `struct pattern type '…' is unrelated to subject type '…'`

## What went wrong

A pattern can only match a type that the subject can actually be: the same struct, or a struct that extends it.

**How to fix it:** Use a pattern type related to '…'.

## Example

<!-- doc-error -->
```km
struct P
    x: int

struct Z
    y: int

void main()
    let p = new P(1)
    match p
        case Z(y: 1)
            print(1)
        else
            print(2)
```

## Fixed

```km
struct P
    x: int

void main()
    let p = new P(1)
    match p
        case P(x: 1)
            print(1)
        else
            print(2)
```
