# K0050: possibly null operand

Message: `… operand of '…' is possibly null`

## What went wrong

The operand has a nullable type (`T?`), so it may hold `null` at run time, and arithmetic on null is meaningless. The compiler makes you handle the null case before using the value.

**How to fix it:** Test it first, for example `if x != null then ...`, or give it a default.

## Example

<!-- doc-error -->
```km
fn maybe(n: int): int?
    if n > 0 then
        return n
    return null

void main()
    let x = maybe(0)
    print(x + 1)
```

## Fixed

```km
fn maybe(n: int): int?
    if n > 0 then
        return n
    return null

void main()
    let x = maybe(0)
    if x != null then
        print(x + 1)
```
