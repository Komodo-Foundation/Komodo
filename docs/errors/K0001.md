# K0001: undefined name

Message: `undefined name '…'`

## What went wrong

The compiler looked for a variable, parameter, macro or function called '{1}' and found none in scope. Names must be declared with `let` (or as parameters) before the line that uses them.

**How to fix it:** Check the spelling, or declare '…' with `let … = ...` before this line.

## Example

<!-- doc-error -->
```km
void main()
    let count = 10
    print(cont)
```

## Fixed

```km
void main()
    let count = 10
    print(count)
```
