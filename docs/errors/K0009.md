# K0009: `is` needs a type

Message: ``is` expects a known type name on the right`

## What went wrong

`x is Type` tests the runtime type of x, so its right-hand side must be the name of a struct or class, not an expression.

**How to fix it:** Write a type name after `is`, for example `x is Circle`.

## Example

<!-- doc-error -->
```km
struct Circle
    r: int

void main()
    let c = new Circle(1)
    console.print(c is 5)
```

## Fixed

```km
struct Circle
    r: int

void main()
    let c = new Circle(1)
    console.print(c is Circle)
```
