# K0123: identical overloads

Message: `duplicate function '…' — two overloads have identical parameter types`

## What went wrong

Overloads are chosen by their parameter types, so two definitions with the same parameter types could never be told apart.

**How to fix it:** Change a parameter type, or rename one function.

## Example

<!-- doc-error -->
```km
fn f(a: int): int
    return a

fn f(b: int): int
    return b

void main()
    print(f(1))
```

## Fixed

```km
fn f(a: int): int
    return a

fn f(b: string): int
    return 1

void main()
    print(f(1))
```
