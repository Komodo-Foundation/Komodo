# K0105: export return type

Message: `export fn '…': return type '…' can't cross the C ABI…`

## What went wrong

Only machine-sized values can be returned to C directly: int and sized ints, bool, float, f32, string, or an `extern type` handle.

**How to fix it:** Return one of the supported types.

## Example

<!-- doc-skip -->
```km
export fn make(): [int]
    return [1]
```

## Fixed

<!-- doc-skip -->
```km
export fn make(): int
    return 1
```
