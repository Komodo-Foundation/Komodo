# K0185: link outside a module

Message: ``link` may only be used inside a module…`

## What went wrong

`link` tells the linker about a C library, and that declaration belongs in a module file (`.kmm` starting with `module name`).

**How to fix it:** Move the `link` line into a module file.

## Example

<!-- doc-error -->
```km
link m

void main()
    console.print(1)
```

## Fixed

```km
void main()
    console.print(1)
```
