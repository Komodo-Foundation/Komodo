# K0062: return value from a void function

Message: `a void function cannot return a value`

## What went wrong

A function declared `void` returns nothing, so `return` may not carry a value in it.

**How to fix it:** Remove the value, or declare the function with a return type, for example `fn f(): int`.

## Example

<!-- doc-error -->
```km
void show()
    return 5

void main()
    show()
```

## Fixed

```km
fn show(): int
    return 5

void main()
    console.print(show())
```
