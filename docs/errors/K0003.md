# K0003: assignment to undeclared variable

Message: `assignment to undeclared variable '…'`

## What went wrong

An assignment can only change a variable that already exists. '…' was never declared, so there is nothing to assign to.

**How to fix it:** Declare it first with `let … = ...`.

## Example

<!-- doc-error -->
```km
void main()
    total = 5
    console.print(total)
```

## Fixed

```km
void main()
    let total = 5
    console.print(total)
```
