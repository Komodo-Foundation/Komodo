# K0020: wrong argument type

Message: `argument … to '…': type '…' is not assignable to '…'`

## What went wrong

Each argument must have the type the function declared for that parameter. A '{3}' cannot stand in for a '{4}', because the function body would then treat the bytes as the wrong kind of value.

**How to fix it:** Pass a value of type '…', or convert it first (for example `string(x)` or `int(x)`).

## Example

<!-- doc-error -->
```km
fn add(a: int, b: int): int
    return a + b

void main()
    print(add("x", 2))
```

## Fixed

```km
fn add(a: int, b: int): int
    return a + b

void main()
    print(add(1, 2))
```
