# K0020: wrong argument type

Message: `argument … to '…': type '…' is not assignable to '…'`

## What went wrong

Each argument must have the type the function declared for that parameter. A value of type '…' cannot stand in for '…', because the function body would then treat it as the wrong kind of value.

**How to fix it:** Pass a value of type '…', or convert it first (for example `string(x)` or `int(x)`).

## Example

<!-- doc-error -->
```km
fn add(a: int, b: int): int
    return a + b

void main()
    print(add("x", 2))
```

## Fixed

```km
fn add(a: int, b: int): int
    return a + b

void main()
    print(add(1, 2))
```
