# K0143: float in a pattern

Message: `struct pattern cannot match on `float` field '…' yet`

## What went wrong

Exact comparison of floating-point values is rarely what you want, so patterns do not support it yet.

**How to fix it:** Bind the field to a name and compare it in an `if`.

## Example

<!-- doc-error -->
```km
struct P
    x: float

void main()
    let p = new P(1.0)
    match p
        case P(x: 1.0)
            print(1)
```

## Fixed

```km
struct P
    x: float

void main()
    let p = new P(1.0)
    if p.x == 1.0 then
        print("one")
```
