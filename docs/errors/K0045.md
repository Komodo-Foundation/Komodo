# K0045: assert arguments

Message: `'assert' takes a condition and an optional message, got … argument(s)`

## What went wrong

`assert(cond)` and `assert(cond, "message")` are the only forms.

**How to fix it:** Write `assert(condition)` or `assert(condition, "what went wrong")`.

## Example

<!-- doc-error -->
```km
void main()
    assert()
```

## Fixed

```km
void main()
    assert(1 + 1 == 2, "arithmetic works")
```
