# K0144: pattern literal type

Message: `pattern for field '…': literal of type '…' is not comparable to field type '…'`

## What went wrong

A literal in a pattern is compared with the field's value, so the two must have the same type.

**How to fix it:** Use a literal of the field's type.

## Example

<!-- doc-error -->
```km
struct P
    x: int

void main()
    let p = new P(1)
    match p
        case P(x: "one")
            console.print(1)
        else
            console.print(2)
```

## Fixed

```km
struct P
    x: int

void main()
    let p = new P(1)
    match p
        case P(x: 1)
            console.print(1)
        else
            console.print(2)
```
