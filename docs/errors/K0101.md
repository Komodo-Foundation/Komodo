# K0101: export overloaded

Message: `export fn '…' cannot be overloaded…`

## What went wrong

Each exported function becomes one C symbol, and a C symbol names exactly one function.

**How to fix it:** Give each exported function a different name.

## Example

<!-- doc-error -->
```km
export fn f(a: int): int
    return a

export fn f(a: string): int
    return 1
```

## Fixed

```km
export fn f(a: int): int
    return a

export fn g(a: string): int
    return 1
```
