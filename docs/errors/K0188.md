# K0188: unexpected top-level token

Message: `Unexpected top-level token…`

## What went wrong

Only declarations (`fn`, `void`, `mut`, `struct`, `class`, `enum`, `let`, `import`, `extern`, `link`) may appear at the top of a file.

**How to fix it:** Check for a stray character, or an indent that closed the function too early.

## Example

<!-- doc-error -->
```km
void main(
    console.print(1)
```

## Fixed

```km
void main()
    console.print(1)
```
