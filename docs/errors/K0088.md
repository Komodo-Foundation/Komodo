# K0088: constructing a handle

Message: `cannot construct `extern type …` — it is an opaque C handle; obtain one from a C function`

## What went wrong

An `extern type` stands for something C code creates and owns, so Komodo cannot build one with `new`.

**How to fix it:** Call the C function that returns the handle.

## Example

<!-- doc-skip -->
```km
extern type Window

void main()
    let w = new Window()
```

## Fixed

<!-- doc-skip -->
```km
extern type Window
extern fn make_window(): Window

void main()
    let w = make_window()
```
