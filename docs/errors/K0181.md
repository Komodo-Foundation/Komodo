# K0181: range as a value

Message: `a range `a to b` is only valid in a `for` loop or a slice, not as a value`

## What went wrong

Ranges are syntax for `for` headers and slices such as `a[1 to 3]`. They are not values you can store.

**How to fix it:** Use `for i = a to b`, or make an array with `[a, b]`.

## Example

<!-- doc-error -->
```km
void main()
    let r = 1 to 4
    print(r)
```

## Fixed

```km
void main()
    for r = 1 to 4
        print(r)
```
