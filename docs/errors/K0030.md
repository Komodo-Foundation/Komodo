# K0030: field access on a non-object

Message: `field access on a non-object (type '…')`

## What went wrong

The `.name` syntax reads a field of a struct or class. Values of type '…' have no fields.

**How to fix it:** Check that the value in front of the `.` is a struct or class instance.

## Example

<!-- doc-error -->
```km
void main()
    let n = 5
    console.print(n.value)
```

## Fixed

```km
struct Box
    value: int

void main()
    let n = new Box(5)
    console.print(n.value)
```
