# K0024: type mismatch

Message: `…: type '…' is not assignable to '…'`

## What went wrong

A value was used where a different type is required. Komodo does not convert between types silently, because that hides bugs.

**How to fix it:** Use a value of type '…', or convert it explicitly (`string(x)`, `int(x)`).

## Example

<!-- doc-error -->
```km
fn half(n: int): int
    return n / 2

fn name(): int
    return "ada"

void main()
    print(half(4), name())
```

## Fixed

```km
fn half(n: int): int
    return n / 2

fn name(): string
    return "ada"

void main()
    print(half(4), name())
```
