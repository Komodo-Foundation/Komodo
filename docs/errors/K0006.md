# K0006: no such method

Message: `type '…' has no method '…'`

## What went wrong

A method call `value.name(...)` needs a method called 'name' on the value's class. '{1}' has no method '{2}'.

**How to fix it:** Check the spelling, or add `…` to the class '…'. Structs hold fields only.

## Example

<!-- doc-error -->
```km
class Counter
    n: int = 0
    mut bump()
        n += 1

void main()
    let c = new Counter()
    c.bumb()
```

## Fixed

```km
class Counter
    n: int = 0
    mut bump()
        n += 1

void main()
    let c = new Counter()
    c.bump()
```
