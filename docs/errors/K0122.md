# K0122: no matching overload

Message: `no overload of '…' matches the argument types`

## What went wrong

'{1}' has several definitions, but none of them accepts arguments of these types.

**How to fix it:** Convert the arguments, or add an overload for these types.

## Example

<!-- doc-error -->
```km
fn f(a: int): int
    return a

fn f(a: string): string
    return a

void main()
    print(f(1.5))
```

## Fixed

```km
fn f(a: int): int
    return a

fn f(a: string): string
    return a

void main()
    print(f(1))
```
