# K0043: wrong number of constructor arguments

Message: `constructor '…' takes … argument(s), got …`

## What went wrong

`new` calls the class's constructor, which declares how many values it needs.

**How to fix it:** Pass … argument(s) to `new …(...)`.

## Example

<!-- doc-error -->
```km
class Counter
public
    constructor(start: int)
        m_n = start
private
    m_n: int = 0

void main()
    let c = new Counter()
```

## Fixed

```km
class Counter
public
    constructor(start: int)
        m_n = start
private
    m_n: int = 0

void main()
    let c = new Counter(1)
```
