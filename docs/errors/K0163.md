# K0163: division by zero

Message: `division by zero`

## What went wrong

Dividing by a literal zero fails at run time.

**How to fix it:** Divide by a non-zero value.

## Example

<!-- doc-skip -->
Compile with `komodo --strict`.

```km
void main()
    let n = 5
    console.print(n / 0)
```

## Fixed

<!-- doc-skip -->
```km
void main()
    let n = 5
    console.print(n / 1)
```
