# K0169: reused local name

Message: `'…' is already declared in this function; this `let` reuses it`

## What went wrong

Komodo locals are function-scoped, so a second `let …` in an inner block does not make a new variable: it assigns the existing one, and the new value is still there after the block.

**How to fix it:** Give the inner variable a different name, or drop `let` if reassigning '…' is intended.

## Example

<!-- doc-skip -->
Reported by `komodo lint`.

```km
void main()
    let x = 1
    if x > 0 then
        let x = 5
        print(x)
    print(x)
```

## Fixed

<!-- doc-skip -->
```km
void main()
    let x = 1
    if x > 0 then
        let y = 5
        print(y)
    print(x)
```
