# K0131: moving a borrowed unique value

Message: `cannot move `unique` value out of '…' — it is not a locally owned binding`

## What went wrong

Only a variable that owns the value can give it away. Parameters and globals do not own theirs.

**How to fix it:** Use `copy(x)` instead, or take ownership with a local `let`.

This error appears when a `unique` value is moved out of a binding that does not own it, such as a parameter or a global.
