# K0070: assignment to a macro

Message: `cannot assign to macro '…' (declared with be)`

## What went wrong

`let NAME be value` declares a compile-time macro: every use of the name is replaced by the value, so there is no variable to assign to.

**How to fix it:** Declare it with `let … = ...` if it must change.

## Example

<!-- doc-error -->
```km
void main()
    let limit be 10
    limit = 11
```

## Fixed

```km
void main()
    let limit = 10
    limit = 11
    print(limit)
```
