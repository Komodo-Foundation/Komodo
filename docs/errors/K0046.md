# K0046: builtin takes one argument

Message: `'…' takes exactly one argument`

## What went wrong

`int(x)` and `copy(x)` convert or copy exactly one value.

**How to fix it:** Pass a single argument.

## Example

<!-- doc-error -->
```km
void main()
    console.print(int(1.5, 2.5))
```

## Fixed

```km
void main()
    console.print(int(1.5))
```
