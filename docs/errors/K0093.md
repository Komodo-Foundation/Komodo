# K0093: default must be a literal

Message: `default value of parameter '…' must be a literal`

## What went wrong

A default is copied into each call that omits the argument, so it must be a plain literal such as 3, "x" or true.

**How to fix it:** Use a literal, or compute the value inside the function.

## Example

<!-- doc-error -->
```km
fn f(a: int, b: int = 1 + 1): int
    return a + b

void main()
    console.print(f(1))
```

## Fixed

```km
fn f(a: int, b: int = 2): int
    return a + b

void main()
    console.print(f(1))
```
