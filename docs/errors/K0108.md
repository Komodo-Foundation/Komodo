# K0108: unsupported extern variable type

Message: `extern variable '…': type '…' is not supported…`

## What went wrong

An `extern let` names a C global, and only machine-sized types can be read from one directly.

**How to fix it:** Use int, sized ints, bool, float, f32, string or an `extern type` handle.

## Example

<!-- doc-skip -->
```km
extern let xs: [int]

void main()
    print(1)
```

## Fixed

<!-- doc-skip -->
```km
extern let xs: int

void main()
    print(1)
```
