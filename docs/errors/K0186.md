# K0186: expected case or else

Message: `expected `case` or `else` in match, got …`

## What went wrong

Inside a `match`, the indented lines must be `case` arms or a final `else`.

**How to fix it:** Start each arm with `case value`.

## Example

<!-- doc-error -->
```km
void main()
    let n = 1
    match n
        console.print("x")
```

## Fixed

```km
void main()
    let n = 1
    match n
        case 1
            console.print("one")
        else
            console.print("other")
```
