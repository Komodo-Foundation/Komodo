# K0182: `?` on an index

Message: `'?' applies to calls, not indexing`

## What went wrong

A trailing `?` catches an error thrown by a call. Indexing is not a call.

**How to fix it:** Check `#a` first, or wrap the indexing in a function and call that with `?`.

## Example

<!-- doc-error -->
```km
void main()
    let a = [1]
    print(a[5]?)
```

## Fixed

```km
void main()
    let a = [1]
    if #a > 5 then
        print(a[5])
```
