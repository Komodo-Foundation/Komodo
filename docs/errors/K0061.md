# K0061: continue outside a loop

Message: ``continue` outside a loop`

## What went wrong

`continue` jumps to the next iteration of the nearest enclosing `while` or `for` loop, so it needs one around it.

**How to fix it:** Put the `continue` inside a loop.

## Example

<!-- doc-error -->
```km
void main()
    continue
```

## Fixed

```km
void main()
    for i = 1 to 3
        if i == 2 then continue
        console.print(i)
```
