# K0064: missing return on some path

Message: `function '…' must return a value on every path`

## What went wrong

A function with a return type must end in a `return` (or `throw`) no matter which branch runs. Here control can reach the end of '{1}' without returning anything.

**How to fix it:** Add a final `return`, or an `else` branch that returns.

## Example

<!-- doc-error -->
```km
fn pick(n: int): int
    if n > 0 then
        return 1

void main()
    print(pick(3))
```

## Fixed

```km
fn pick(n: int): int
    if n > 0 then
        return 1
    return 0

void main()
    print(pick(3))
```
