# K0140: pattern on a non-struct

Message: `struct pattern '…(…)' used on non-struct subject of type '…'`

## What went wrong

`case Type(field: ...)` takes a struct apart, so the value being matched must itself be a struct.

**How to fix it:** Match on a struct value, or use plain `case` values.

## Example

<!-- doc-error -->
```km
struct P
    x: int

void main()
    let n = 5
    match n
        case P(x: 1)
            console.print(1)
        else
            console.print(2)
```

## Fixed

```km
void main()
    let n = 5
    match n
        case 5
            console.print(1)
        else
            console.print(2)
```
