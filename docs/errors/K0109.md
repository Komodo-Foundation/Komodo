# K0109: callback parameter type

Message: `'…' cannot be a C callback: parameter type '…' is not a plain machine word`

## What went wrong

A Komodo function passed to C is called by C code, so its parameters must be plain machine words or doubles.

**How to fix it:** Change the parameter to int, bool, float or a handle.

## Example

<!-- doc-error -->
```km
extern fn run_cb(cb: int): int

fn scale(xs: [int], n: int): int
    return n

void main()
    let r = run_cb(scale)
```

## Fixed

```km
extern fn run_cb(cb: int): int

fn scale(n: int): int
    return n

void main()
    let r = run_cb(scale)
```
