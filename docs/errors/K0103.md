# K0103: export parameter type

Message: `export fn '…': parameter '…' has type '…', which can't cross the C ABI…`

## What went wrong

Only machine-sized values can be passed to C directly: int and sized ints, bool, float, f32, string, or an `extern type` handle. Arrays and Komodo structs have a layout C does not know.

**How to fix it:** Use one of the supported types.

## Example

<!-- doc-error -->
```km
export fn total(xs: [int]): int
    return 0
```

## Fixed

```km
export fn total(n: int): int
    return n
```
