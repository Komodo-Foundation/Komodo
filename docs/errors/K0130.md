# K0130: use after move

Message: `use of moved value '…' — …`

## What went wrong

A `unique` value has exactly one owner. Binding it to another name, or passing it on, moves ownership, and the old name is left with nothing.

**How to fix it:** Use the new owner, or `copy(x)` to keep a second value.

## Example

<!-- doc-error -->
```km
unique struct Handle
    id: int

void main()
    let a = new Handle(1)
    let b = a
    console.print(b.id)
    console.print(a.id)
```

## Fixed

```km
unique struct Handle
    id: int

void main()
    let a = new Handle(1)
    let b = a
    console.print(b.id)
```
