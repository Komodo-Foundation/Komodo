# K0166: untyped parameter

Message: `parameter '…' has no type annotation (implicit any)`

## What went wrong

Under `--strict`, parameters must say their type, so mistakes are caught where the function is called.

**How to fix it:** Write `…: int` (or the type it should have).

## Example

<!-- doc-skip -->
Compile with `komodo --strict`.

```km
fn add(a, b): int
    return 1

void main()
    print(add(1, 2))
```

## Fixed

<!-- doc-skip -->
```km
fn add(a: int, b: int): int
    return a + b

void main()
    print(add(1, 2))
```
