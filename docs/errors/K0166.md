# K0166: untyped parameter

Message: `parameter '…' has no type annotation (implicit any)`

## What went wrong

Under `--strict`, method parameters must say their type, so mistakes are caught where the method is called.

**How to fix it:** Write `…: int` (or the type it should have).

## Example

<!-- doc-skip -->
Compile with `komodo --strict`.

```km
class C
    fn f(a): int
        return 1

void main()
    console.print(1)
```

## Fixed

<!-- doc-skip -->
```km
class C
    fn f(a: int): int
        return a

void main()
    console.print(1)
```
