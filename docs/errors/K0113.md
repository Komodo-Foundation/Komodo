# K0113: extern symbol must be a string

Message: `expected a string literal after `=` (the C symbol name) in extern…`

## What went wrong

`extern fn name(...) = "c_symbol"` binds a Komodo name to a C symbol, and the symbol is written as a string literal.

**How to fix it:** Put the C symbol in quotes after the `=`.

## Example

<!-- doc-skip -->
```km
extern fn f(x: int): int = 42

void main()
    print(1)
```

## Fixed

<!-- doc-skip -->
```km
extern fn f(x: int): int = "f_impl"

void main()
    print(1)
```
