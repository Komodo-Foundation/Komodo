# K0104: export with defaults

Message: `export fn '…' cannot have default parameter values…`

## What went wrong

C has no default arguments: a C caller always passes every argument.

**How to fix it:** Remove the default values.

## Example

<!-- doc-skip -->
```km
export fn f(a: int = 3): int
    return a
```

## Fixed

<!-- doc-skip -->
```km
export fn f(a: int): int
    return a
```
