# K0110: callback return type

Message: `'…' cannot be a C callback: return type '…' is not a plain machine word`

## What went wrong

C code calling back into Komodo expects a plain machine word or double as the result.

**How to fix it:** Return int, bool, float or a handle.

## Example

<!-- doc-skip -->
```km
extern fn run_cb(cb: int): int

fn scale(n: int): [int]
    return [n]

void main()
    let r = run_cb(scale)
```

## Fixed

<!-- doc-skip -->
```km
extern fn run_cb(cb: int): int

fn scale(n: int): int
    return n

void main()
    let r = run_cb(scale)
```
