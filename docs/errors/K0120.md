# K0120: no overload with that arity

Message: `no overload of '…' takes … argument(s)`

## What went wrong

'{1}' has several definitions, but none of them accepts {2} argument(s).

**How to fix it:** Call it with the number of arguments one of the overloads declares.

## Example

<!-- doc-error -->
```km
fn f(a: int): int
    return a

fn f(a: string): string
    return a

void main()
    print(f(1, 2))
```

## Fixed

```km
fn f(a: int): int
    return a

fn f(a: string): string
    return a

void main()
    print(f(1))
```
