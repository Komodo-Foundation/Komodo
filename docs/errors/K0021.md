# K0021: wrong handle type

Message: `argument … to extern '…': type '…' is not assignable to handle type '…'`

## What went wrong

An `extern type` is an opaque C handle. Handles are distinct types: a Window is not a Renderer, and neither is an int, so the compiler refuses to mix them up.

**How to fix it:** Pass a value of type '…', obtained from the C function that creates one.

## Example

<!-- doc-skip -->
```km
extern type Window
extern type Renderer
extern fn make_window(): Window
extern void use_renderer(r: Renderer)

void main()
    let w = make_window()
    use_renderer(w)
```

## Fixed

<!-- doc-skip -->
```km
extern type Window
extern type Renderer
extern fn make_renderer(): Renderer
extern void use_renderer(r: Renderer)

void main()
    let r = make_renderer()
    use_renderer(r)
```
