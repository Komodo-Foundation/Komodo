# K0091: defaults on an overloaded function

Message: `overloaded function '…' cannot have default parameter values`

## What went wrong

Overloads are chosen by the number and types of the arguments. Defaults would make several overloads match the same call.

**How to fix it:** Remove the defaults, or give the functions different names.

## Example

<!-- doc-error -->
```km
fn f(a: int, b: int = 1): int
    return a + b

fn f(a: string): string
    return a

void main()
    console.print(f(1))
```

## Fixed

```km
fn f(a: int, b: int): int
    return a + b

fn f(a: string): string
    return a

void main()
    console.print(f(1, 1))
```
