# K0047: copy of a handle

Message: `cannot `copy` the opaque handle type '…'`

## What went wrong

An `extern type` handle points at memory owned by C code, so a deep copy would not duplicate the real object.

**How to fix it:** Ask the C library for a new handle instead.

## Example

<!-- doc-skip -->
```km
extern type Window
extern fn make_window(): Window

void main()
    let w = make_window()
    let v = copy(w)
```

## Fixed

<!-- doc-skip -->
```km
extern type Window
extern fn make_window(): Window

void main()
    let w = make_window()
    let v = make_window()
```
