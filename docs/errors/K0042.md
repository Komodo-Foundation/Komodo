# K0042: wrong number of method arguments

Message: `method '….…' takes … argument(s), got …`

## What went wrong

A method call must supply exactly the parameters the method declares.

**How to fix it:** Pass … argument(s) to '….…'.

## Example

<!-- doc-error -->
```km
class Counter
    n: int = 0
    mut add(by: int)
        n += by

void main()
    let c = new Counter()
    c.add()
```

## Fixed

```km
class Counter
    n: int = 0
    mut add(by: int)
        n += by

void main()
    let c = new Counter()
    c.add(2)
```
