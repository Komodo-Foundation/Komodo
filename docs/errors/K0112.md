# K0112: extern variable needs a type

Message: `extern variable '…' needs a type…`

## What went wrong

Komodo cannot read the type of a C global, so an `extern let` must say it.

**How to fix it:** Write `extern let …: int`.

## Example

<!-- doc-skip -->
```km
extern let counter

void main()
    print(1)
```

## Fixed

<!-- doc-skip -->
```km
extern let counter: int

void main()
    print(1)
```
