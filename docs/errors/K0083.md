# K0083: duplicate global

Message: `duplicate top-level name '…'`

## What went wrong

'…' is declared at top level more than once, so the name would mean two things.

**How to fix it:** Rename or delete one of the declarations.

## Example

<!-- doc-error -->
```km
let total = 0
let total = 1

void main()
    print(total)
```

## Fixed

```km
let total = 0

void main()
    print(total)
```
