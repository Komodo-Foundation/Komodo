# K0072: pure function mutates state

Message: `pure `fn …` mutates state — declare it `mut``

## What went wrong

A `fn` promises not to change anything its caller can see, which lets callers rely on it. Writing a field or an array element breaks that promise.

**How to fix it:** Declare it `mut …` (or `void`) if it is meant to change state.

## Example

<!-- doc-error -->
```km
struct Box
    v: int = 0

fn poke(b: Box): int
    b.v = 9
    return b.v

void main()
    print(poke(new Box()))
```

## Fixed

```km
struct Box
    v: int = 0

mut poke(b: Box): int
    b.v = 9
    return b.v

void main()
    print(poke(new Box()))
```
