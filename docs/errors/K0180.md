# K0180: one-line if/else

Message: `unexpected 'else': a one-line `if c then X else Y` is not supported…`

## What went wrong

The one-line `if c then X` form takes no `else`, to keep the grammar unambiguous.

**How to fix it:** Write the branches on separate indented lines.

## Example

<!-- doc-error -->
```km
void main()
    let n = 7
    if n % 2 == 0 then console.print("even") else console.print("odd")
```

## Fixed

```km
void main()
    let n = 7
    if n % 2 == 0 then
        console.print("even")
    else
        console.print("odd")
```
