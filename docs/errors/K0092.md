# K0092: default out of order

Message: `parameter '…' needs a default value, because it follows a parameter that has one`

## What went wrong

When a call leaves arguments out, the missing ones must be the last ones. So once a parameter has a default, every parameter after it needs one too.

**How to fix it:** Give '…' a default, or move the defaulted parameters to the end.

## Example

<!-- doc-error -->
```km
fn f(a: int = 1, b: int): int
    return a + b

void main()
    console.print(f(1, 2))
```

## Fixed

```km
fn f(b: int, a: int = 1): int
    return a + b

void main()
    console.print(f(2))
```
