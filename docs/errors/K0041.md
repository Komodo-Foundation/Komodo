# K0041: wrong number of arguments

Message: `'…' takes … argument(s), got …`

## What went wrong

A call must supply exactly the parameters the function declares (trailing parameters with a default value may be left out).

**How to fix it:** Pass … argument(s), as '…' declares.

## Example

<!-- doc-error -->
```km
fn add(a: int, b: int): int
    return a + b

void main()
    console.print(add(1))
```

## Fixed

```km
fn add(a: int, b: int): int
    return a + b

void main()
    console.print(add(1, 2))
```
