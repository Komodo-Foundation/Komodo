# K0187: unexpected token

Message: `unexpected '…'…`

## What went wrong

The parser found a token that cannot start or continue an expression or statement at this position.

**How to fix it:** Check the line for a missing operator, a stray character or a wrong indent.

## Example

<!-- doc-error -->
```km
void main()
  console.print(1)
    console.print(2)
```

## Fixed

```km
void main()
    console.print(1)
    console.print(2)
```
