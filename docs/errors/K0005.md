# K0005: no such field

Message: `type '…' has no field '…'`

## What went wrong

The struct or class '…' declares a fixed set of fields, and '…' is not one of them. Fields cannot be added to a value after the fact.

**How to fix it:** Check the spelling, or add a `…` field to '…'.

## Example

<!-- doc-error -->
```km
struct Point
    x: int
    y: int

void main()
    let p = new Point(1, 2)
    console.print(p.z)
```

## Fixed

```km
struct Point
    x: int
    y: int

void main()
    let p = new Point(1, 2)
    console.print(p.y)
```
