# K0132: moving a unique field

Message: `cannot move `unique` value of type '…' out of field '…' — …`

## What went wrong

A field is owned by the struct that holds it. Taking it out would leave the struct with a hole.

**How to fix it:** Move the whole owning value, or use `copy(...)`.

This error appears when a `unique` value is moved out of a struct field.
