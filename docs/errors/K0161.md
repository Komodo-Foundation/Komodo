# K0161: self-assignment

Message: `self-assignment of '…' has no effect`

## What went wrong

Assigning a variable to itself changes nothing, so it is nearly always a typo for a different name.

**How to fix it:** Check which variable you meant to assign.

## Example

<!-- doc-skip -->
Compile with `komodo --strict`.

```km
void main()
    let a = 1
    a = a
    console.print(a)
```

## Fixed

<!-- doc-skip -->
```km
void main()
    let a = 1
    let b = 2
    a = b
    console.print(a)
```
