# K0106: bad C symbol character

Message: `extern…: character '…' is not allowed in the C symbol "…"`

## What went wrong

The name after `=` is handed to the linker as a C symbol, and C identifiers may only contain letters, digits and underscores.

**How to fix it:** Use a valid C identifier, for example "my_name".

## Example

<!-- doc-skip -->
```km
extern fn f(x: int): int = "bad-name"

void main()
    console.print(f(1))
```

## Fixed

<!-- doc-skip -->
```km
extern fn f(x: int): int = "bad_name"

void main()
    console.print(1)
```
