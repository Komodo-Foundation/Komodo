# K0012: module not found

Message: `cannot find module '…'`

## What went wrong

`import …` loads a file called `….kmm`. The compiler searched the importing file's directory tree and then its own standard library, and found neither.

**How to fix it:** Check the spelling, or create `….kmm` next to your program. Standard modules include console, math, string, file and os.

## Example

<!-- doc-error -->
```km
import nosuch

void main()
    print(1)
```

## Fixed

```km
import console

void main()
    console.print(1)
```
