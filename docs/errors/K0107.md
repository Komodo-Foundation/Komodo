# K0107: C symbol starts with a digit

Message: `extern '…': the C symbol "…" cannot start with a digit`

## What went wrong

C identifiers cannot start with a digit.

**How to fix it:** Start the symbol with a letter or an underscore.

## Example

<!-- doc-error -->
```km
extern fn f(x: int): int = "1abc"

void main()
    print(1)
```

## Fixed

```km
extern fn f(x: int): int = "abc1"

void main()
    print(1)
```
