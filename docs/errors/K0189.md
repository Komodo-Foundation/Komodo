# K0189: modifier without a type

Message: `expected `struct` or `class` after type modifier`

## What went wrong

`abstract` and `unique` modify a struct or class declaration, so one must follow.

**How to fix it:** Write `abstract struct Name` or `unique struct Name`.

## Example

<!-- doc-error -->
```km
abstract Shape
    tag: int

void main()
    console.print(1)
```

## Fixed

```km
abstract struct Shape
    tag: int

void main()
    console.print(1)
```
