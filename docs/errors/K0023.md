# K0023: wrong field type

Message: `field '…' of '…': type '…' is not assignable to '…'`

## What went wrong

`new Type(...)` fills the fields in order, and each value must have the type the field was declared with.

**How to fix it:** Give '….…' a value of type '…'.

## Example

<!-- doc-error -->
```km
struct Point
    x: int
    y: int

void main()
    let p = new Point(1, "two")
    console.print(p.x)
```

## Fixed

```km
struct Point
    x: int
    y: int

void main()
    let p = new Point(1, 2)
    console.print(p.x)
```
