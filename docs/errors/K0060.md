# K0060: break outside a loop

Message: ``break` outside a loop`

## What went wrong

`break` leaves the nearest enclosing `while` or `for` loop, so it needs one around it.

**How to fix it:** Put the `break` inside a loop, or use `return` to leave a function.

## Example

<!-- doc-error -->
```km
void main()
    break
```

## Fixed

```km
void main()
    while true do
        break
```
