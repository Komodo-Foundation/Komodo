# K0008: unknown base type

Message: `type '…' inherits unknown type '…'`

## What went wrong

A type can only extend a struct or class that is declared somewhere in the program. '{2}' is not.

**How to fix it:** Check the spelling of the base type, or declare it.

## Example

<!-- doc-error -->
```km
struct Circle : Shap
    r: int

void main()
    let c = new Circle(1)
    print(c.r)
```

## Fixed

```km
struct Shape
    tag: int = 0

struct Circle : Shape
    r: int = 0

void main()
    let c = new Circle(0, 1)
    print(c.r)
```
