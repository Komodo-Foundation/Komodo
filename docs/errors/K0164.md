# K0164: self comparison

Message: `'…' compares a value with itself`

## What went wrong

Comparing a value with itself always gives the same answer, so it is almost always a typo.

**How to fix it:** Compare against a different value.

## Example

<!-- doc-skip -->
Compile with `komodo --strict`.

```km
void main()
    let y = 3
    if y == y then
        print("same")
```

## Fixed

<!-- doc-skip -->
```km
void main()
    let y = 3
    let z = 4
    if y == z then
        print("same")
```
