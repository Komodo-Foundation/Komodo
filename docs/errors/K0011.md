# K0011: private to module

Message: `'…' is private to module '…'`

## What went wrong

Members in a module's `private` section can be used only from inside that module. Callers see just the `public` section, so the module can change the rest freely.

**How to fix it:** Call a `public` member of '…' instead, or move '…' to its `public` section.

## Example

File `secret.kmm`:

<!-- doc-skip -->
```km
module secret
public
    fn open(): int
        return key()
private
    fn key(): int
        return 7
```

<!-- doc-skip -->
```km
import secret

void main()
    console.print(secret::key())
```

## Fixed

<!-- doc-skip -->
```km
import secret

void main()
    console.print(secret::open())
```
