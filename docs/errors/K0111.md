# K0111: export needs a body

Message: ``export` needs a free function with a body: '…'`

## What went wrong

`export fn` publishes Komodo code to C, so it needs a body. To use a C function from Komodo, write `extern fn` instead.

**How to fix it:** Add a body, or use `extern fn` to declare a C function.

## Example

<!-- doc-error -->
```km
export fn f(a: int): int
```

## Fixed

```km
export fn f(a: int): int
    return a
```
