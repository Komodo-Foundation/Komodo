# K0028: `in` with an array

Message: ``in`: '…' can't be an element of '…'`

## What went wrong

`x in array` tests membership, so x must have the array's element type. Here the two types differ, so the answer could never be true.

**How to fix it:** Look for a value of the array's element type.

## Example

<!-- doc-error -->
```km
void main()
    let names = ["ada", "bo"]
    print(3 in names)
```

## Fixed

```km
void main()
    let names = ["ada", "bo"]
    print("bo" in names)
```
