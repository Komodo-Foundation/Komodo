# K0085: global needs a type or value

Message: `top-level '…' needs a type annotation or an initialiser`

## What went wrong

A global variable needs either a starting value or a declared type, so the compiler can tell what it holds.

**How to fix it:** Write `let …: int = 0` or `let … = 0`.

## Example

<!-- doc-error -->
```km
let total

void main()
    console.print(1)
```

## Fixed

```km
let total = 0

void main()
    console.print(total)
```
