# K0168: variable without a type

Message: `'…' has no type annotation and no initialiser`

## What went wrong

With neither a type nor a starting value, the compiler cannot tell what the variable holds.

**How to fix it:** Write `let …: int` or `let … = 0`.

## Example

<!-- doc-skip -->
Compile with `komodo --strict`.

```km
void main()
    let x
    x = 1
    print(x)
```

## Fixed

<!-- doc-skip -->
```km
void main()
    let x = 1
    print(x)
```
