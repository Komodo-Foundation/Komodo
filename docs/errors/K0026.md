# K0026: operator on a handle

Message: `operator '…' is not defined for the opaque handle type '…'`

## What went wrong

An `extern type` handle is just an opaque pointer owned by C code, so arithmetic and ordering on it make no sense.

**How to fix it:** Pass the handle to the C function that works on it.

## Example

<!-- doc-skip -->
```km
extern type Window
extern fn make_window(): Window

void main()
    let w = make_window()
    print(w + 1)
```

## Fixed

<!-- doc-skip -->
```km
extern type Window
extern fn make_window(): Window

void main()
    let w = make_window()
    print(w)
```
