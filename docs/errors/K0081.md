# K0081: duplicate type

Message: `duplicate type '…'`

## What went wrong

A struct, class or enum called '{1}' is declared more than once, so the name would mean two things.

**How to fix it:** Rename one of the types, or delete the duplicate.

## Example

<!-- doc-error -->
```km
struct Point
    x: int

struct Point
    y: int

void main()
    print(1)
```

## Fixed

```km
struct Point
    x: int

struct Point3
    y: int

void main()
    print(1)
```
