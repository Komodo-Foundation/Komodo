# K0102: export parameter untyped

Message: `export fn '…': parameter '…' needs a type annotation`

## What went wrong

C callers must know every parameter's exact type, so an exported function cannot leave any untyped.

**How to fix it:** Write `…: int` (or the type it should have).

## Example

<!-- doc-error -->
```km
export fn twice(x): int
    return 2
```

## Fixed

```km
export fn twice(x: int): int
    return x * 2
```
