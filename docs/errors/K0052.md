# K0052: possibly null field access

Message: `in '…': value of type '…' is possibly null — narrow it before reading '.…'`

## What went wrong

Reading a field of a nullable value would crash when the value is `null`.

**How to fix it:** Check `value != null` before reading '.…'.

## Example

<!-- doc-error -->
```km
struct Box
    n: int

fn find(k: int): Box?
    if k > 0 then
        return new Box(k)
    return null

void main()
    let b = find(0)
    console.print(b.n)
```

## Fixed

```km
struct Box
    n: int

fn find(k: int): Box?
    if k > 0 then
        return new Box(k)
    return null

void main()
    let b = find(0)
    if b != null then
        console.print(b.n)
```
