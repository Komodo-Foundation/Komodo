# K0167: mut without mutation

Message: ``mut …` has no mutating code — could be `fn` or `void``

## What went wrong

`mut` says a function changes something, but this one changes nothing. A plain `fn` is a stronger promise to its callers.

**How to fix it:** Declare it `fn`.

## Example

<!-- doc-skip -->
Compile with `komodo --strict`.

```km
mut one(): int
    return 1

void main()
    console.print(one())
```

## Fixed

<!-- doc-skip -->
```km
fn one(): int
    return 1

void main()
    console.print(one())
```
