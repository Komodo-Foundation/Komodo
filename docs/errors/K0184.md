# K0184: methods in a struct

Message: `struct bodies hold fields only; use a class for methods`

## What went wrong

A `struct` is plain data. Behaviour belongs in a `class`.

**How to fix it:** Change `struct` to `class`, or move the method into a free function.

## Example

<!-- doc-error -->
```km
struct Counter
    n: int = 0
    mut bump()
        n += 1

void main()
    print(1)
```

## Fixed

```km
class Counter
    n: int = 0
    mut bump()
        n += 1

void main()
    print(1)
```
