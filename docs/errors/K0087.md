# K0087: abstract instantiation

Message: `cannot instantiate abstract type '…'`

## What went wrong

An `abstract` type is only a base for other types and has no complete value of its own.

**How to fix it:** Create one of its concrete subtypes instead.

## Example

<!-- doc-error -->
```km
abstract struct Shape
    tag: int

void main()
    let s = new Shape(1)
```

## Fixed

```km
abstract struct Shape
    tag: int

struct Circle : Shape
    r: int

void main()
    let s = new Circle(0, 1)
    console.print(s.r)
```
