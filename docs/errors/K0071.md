# K0071: reassigning an immutable binding

Message: `cannot reassign immutable binding '…' (declared with `be`)`

## What went wrong

A name declared with `be` is fixed once and for all. Assigning to it later would change the meaning of code already written.

**How to fix it:** Declare it with `let … = ...` if it must change.

## Example

<!-- doc-error -->
```km
void main()
    let n: int be 3
    n = 4
```

## Fixed

```km
void main()
    let n: int = 3
    n = 4
    print(n)
```
