# K0071: assignment to a fixed name

Message: `cannot reassign immutable binding '…' (declared with `be`)`

## What went wrong

Some names are fixed once and cannot be assigned to: names declared with `be`, `self`, and the counter of a `for` loop, which the loop itself advances. Assigning to one would change something the language relies on.

**How to fix it:** Use a separate variable for the value that changes: `let …2 = ...`.

## Example

<!-- doc-error -->
```km
void main()
    for i = 1 to 3
        i = 5
```

## Fixed

```km
void main()
    for i = 1 to 3
        let j = i + 1
        print(j)
```
