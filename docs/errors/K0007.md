# K0007: unknown type in a pattern

Message: `struct pattern names unknown type '…'`

## What went wrong

A `case Type(...)` pattern names the struct it matches, and there is no struct called '{1}'.

**How to fix it:** Check the spelling of the type name.

## Example

<!-- doc-error -->
```km
struct P
    x: int

void main()
    let p = new P(1)
    match p
        case Q(x: 1)
            print("one")
        else
            print("other")
```

## Fixed

```km
struct P
    x: int

void main()
    let p = new P(1)
    match p
        case P(x: 1)
            print("one")
        else
            print("other")
```
