# K0090: defaults on the wrong kind of function

Message: `default parameter values are only allowed on free functions with a body`

## What went wrong

Default values are filled in at the call site, which only works for plain functions that have a body. Methods, constructors and C prototypes cannot take them.

**How to fix it:** Remove the default, or move the logic into a free function.

## Example

<!-- doc-error -->
```km
class Counter
    n: int = 0
    mut bump(by: int = 1)
        n += by

void main()
    let c = new Counter()
    c.bump()
```

## Fixed

```km
class Counter
    n: int = 0
    mut bump(by: int)
        n += by

void main()
    let c = new Counter()
    c.bump(1)
```
