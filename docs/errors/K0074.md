# K0074: macro without a value

Message: ``let … be` needs a value`

## What went wrong

`let NAME be value` defines a macro and the value is what the name expands to.

**How to fix it:** Write `let … be <expression>`.

## Example

<!-- doc-error -->
```km
void main()
    let size be
    print(size)
```

## Fixed

```km
void main()
    let size be 4
    print(size)
```
