# K0044: too many values for `new`

Message: ``new …` given more values than it has fields`

## What went wrong

`new Type(a, b, ...)` fills the fields in declaration order. There are more values than fields, so some value has nowhere to go.

**How to fix it:** Remove the extra values, or add fields to '…'.

## Example

<!-- doc-error -->
```km
struct Point
    x: int
    y: int

void main()
    let p = new Point(1, 2, 3)
    print(p.x)
```

## Fixed

```km
struct Point
    x: int
    y: int

void main()
    let p = new Point(1, 2)
    print(p.x)
```
