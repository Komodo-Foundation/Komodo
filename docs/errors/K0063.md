# K0063: missing return value

Message: `a value function must return a value`

## What went wrong

A function declared with a return type must hand a value back on every `return`; a bare `return` is only for `void` functions.

**How to fix it:** Write `return <value>`.

## Example

<!-- doc-error -->
```km
fn five(): int
    return

void main()
    console.print(five())
```

## Fixed

```km
fn five(): int
    return 5

void main()
    console.print(five())
```
