# K0010: private to class

Message: `'…' is private to class '…'`

## What went wrong

Members in a class's `private` section can only be used by that class's own methods. This keeps the class free to change them without breaking callers.

**How to fix it:** Use a public method of '…' instead, or move '…' to the `public` section.

## Example

<!-- doc-error -->
```km
class Counter
public
    constructor(start: int)
        m_n = start
    fn peek(): int
        return m_n
private
    m_n: int = 0

void main()
    let c = new Counter(3)
    console.print(c.m_n)
```

## Fixed

```km
class Counter
public
    constructor(start: int)
        m_n = start
    fn peek(): int
        return m_n
private
    m_n: int = 0

void main()
    let c = new Counter(3)
    console.print(c.peek())
```
