# K0031: field assignment on a non-object

Message: `field assignment on a non-object (type '…')`

## What went wrong

`a.b = x` writes a field of a struct or class, but the value in front of the `.` has type '{1}', which has no fields.

**How to fix it:** Check that the value in front of the `.` is a struct or class instance.

## Example

<!-- doc-error -->
```km
void main()
    let n = 5
    n.value = 6
```

## Fixed

```km
struct Box
    value: int

void main()
    let n = new Box(5)
    n.value = 6
```
