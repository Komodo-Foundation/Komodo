# K0162: constant condition

Message: ``if` condition is always …`

## What went wrong

The condition is a literal that is always true or always false, so one branch can never run.

**How to fix it:** Remove the `if`, or use a real condition.

## Example

<!-- doc-skip -->
Compile with `komodo --strict`.

```km
void main()
    if true then
        console.print("always")
```

## Fixed

<!-- doc-skip -->
```km
void main()
    let n = 3
    if n > 2 then
        console.print("big")
```
