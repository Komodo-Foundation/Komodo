# K0002: undefined module function

Message: `undefined function '…::…'`

## What went wrong

The module '…' was imported, but it has no member named '…'. A `module::name` call can only reach members the module declares.

**How to fix it:** Check the spelling of '…' in the module, or add it to the module's `public` section.

## Example

File `secret.kmm`:

<!-- doc-skip -->
```km
module secret
public
    fn open(): int
        return 7
```

<!-- doc-skip -->
```km
import secret

void main()
    print(secret::opn())
```

## Fixed

<!-- doc-skip -->
```km
import secret

void main()
    print(secret::open())
```
