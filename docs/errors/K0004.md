# K0004: unknown type in `new`

Message: ``new` of unknown type '…'`

## What went wrong

`new` builds a value of a struct or class, and the compiler has no struct, class or enum called '…'.

**How to fix it:** Check the spelling, or declare `struct …` (or `class …`) above `main`.

## Example

<!-- doc-error -->
```km
struct Point
    x: int

void main()
    let p = new Pont(1)
    console.print(p.x)
```

## Fixed

```km
struct Point
    x: int

void main()
    let p = new Point(1)
    console.print(p.x)
```
