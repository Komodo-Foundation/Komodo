# K0082: duplicate macro

Message: `duplicate macro '…'`

## What went wrong

Two top-level macros are both called '…', so uses of the name would be ambiguous.

**How to fix it:** Rename or delete one of them.

## Example

<!-- doc-error -->
```km
let N be 1
let N be 2

void main()
    print(N)
```

## Fixed

```km
let N be 1

void main()
    print(N)
```
