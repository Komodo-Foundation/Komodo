# K0170: comparison with a bool literal

Message: `comparison with a bool literal; use the value or `not` directly`

## What went wrong

`x == true` is the same as `x`, and `x == false` is the same as `not x`; the longer form only adds noise.

**How to fix it:** Write the bool value itself, or `not` it.

## Example

<!-- doc-skip -->
Reported by `komodo lint`.

```km
void main()
    let ok = true
    if ok == true then
        console.print("yes")
```

## Fixed

<!-- doc-skip -->
```km
void main()
    let ok = true
    if ok then
        console.print("yes")
```
