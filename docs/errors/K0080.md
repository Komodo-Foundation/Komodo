# K0080: duplicate function

Message: `duplicate function '…'`

## What went wrong

Two functions share the name '{1}' and the same parameter types, so a call could not tell them apart.

**How to fix it:** Rename one of them, or give them different parameter types to overload.

## Example

<!-- doc-error -->
```km
fn f(): int
    return 1

fn f(): int
    return 2

void main()
    print(f())
```

## Fixed

```km
fn f(): int
    return 1

fn g(): int
    return 2

void main()
    print(f() + g())
```
