# K0080: duplicate function

Message: `duplicate function '…'`

## What went wrong

Two functions share the name '…' and the compiler cannot tell them apart.

**How to fix it:** Rename one of them, or give them different parameter types to overload.

Two free functions with the same name are treated as overloads, so the common case is reported as [K0123](K0123.md). This code is for other name collisions.
