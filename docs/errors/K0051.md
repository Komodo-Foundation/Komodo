# K0051: possibly null receiver

Message: `…possibly null — narrow it before calling '…'`

## What went wrong

Calling a method on a nullable value would crash when the value is `null`. The compiler asks you to check first.

**How to fix it:** Wrap the call in `if value != null then ...`.

## Example

<!-- doc-error -->
```km
class Box
    n: int = 0
    fn get(): int
        return n

fn find(k: int): Box?
    if k > 0 then
        return new Box(k)
    return null

void main()
    let b = find(0)
    print(b.get())
```

## Fixed

```km
class Box
    n: int = 0
    fn get(): int
        return n

fn find(k: int): Box?
    if k > 0 then
        return new Box(k)
    return null

void main()
    let b = find(0)
    if b != null then
        print(b.get())
```
