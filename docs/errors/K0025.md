# K0025: cannot add these types

Message: `cannot add '…' and '…' (use string(x) or an interpolated string)…`

## What went wrong

`+` adds two numbers or joins two strings, but never mixes a string with a number. Joining them would need a conversion the compiler will not guess.

**How to fix it:** Convert the number first with `string(x)`, or use an interpolated string such as `n = {n}`.

## Example

<!-- doc-error -->
```km
void main()
    let n = 3
    print("n is " + n)
```

## Fixed

```km
void main()
    let n = 3
    print("n is " + string(n))
```
