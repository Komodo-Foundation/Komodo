# K0027: `in` with a string

Message: ``in` on a string wants a string / char on the left, got '…'`

## What went wrong

`x in "text"` asks whether x occurs inside the string, so x must itself be text or a single character.

**How to fix it:** Convert the left side with `string(x)`.

## Example

<!-- doc-error -->
```km
void main()
    print(5 in "a5b")
```

## Fixed

```km
void main()
    print(string(5) in "a5b")
```
