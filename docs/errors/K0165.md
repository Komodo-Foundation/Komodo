# K0165: unused variable

Message: `'…' is declared but never used`

## What went wrong

Under `--strict`, a local that is never read is reported: it is usually a leftover or a misspelt name.

**How to fix it:** Use '…', or delete it.

## Example

<!-- doc-skip -->
Compile with `komodo --strict`.

```km
void main()
    let unused = 5
    print("hi")
```

## Fixed

<!-- doc-skip -->
```km
void main()
    print("hi")
```
