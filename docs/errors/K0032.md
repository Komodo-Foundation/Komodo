# K0032: int() argument

Message: `'int' expects a number, got '…'`

## What went wrong

`int(x)` converts a float to an integer, truncating toward zero. It does not parse text.

**How to fix it:** Pass a float or an int.

## Example

<!-- doc-error -->
```km
void main()
    console.print(int("42"))
```

## Fixed

```km
void main()
    console.print(int(42.9))
```
