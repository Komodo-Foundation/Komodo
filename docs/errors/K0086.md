# K0086: inheritance cycle

Message: `cyclic or unresolved inheritance near '…'`

## What went wrong

Types may extend each other only in a chain that ends at a base type. Here the chain loops back on itself, or leads to a type that does not exist.

**How to fix it:** Break the cycle by removing one of the `: Base` clauses.

## Example

<!-- doc-error -->
```km
struct A : B
    x: int

struct B : A
    y: int

void main()
    print(1)
```

## Fixed

```km
struct B
    y: int

struct A : B
    x: int

void main()
    print(1)
```
