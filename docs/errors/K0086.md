# K0086: unknown or cyclic base type

Message: `cyclic or unresolved inheritance near '…'`

## What went wrong

A type can only extend a struct or class that exists, and a chain of base types must end at one that extends nothing. Here a base type is missing (often a typo), or two types extend each other in a loop.

**How to fix it:** Check the spelling of the base type after the `:`, declare it, or break the cycle.

## Example

<!-- doc-error -->
```km
struct Circle : Shap
    r: int

void main()
    console.print(1)
```

## Fixed

```km
struct Shape
    tag: int = 0

struct Circle : Shape
    r: int = 0

void main()
    console.print(1)
```
