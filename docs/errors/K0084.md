# K0084: template shares a name

Message: `template '…' cannot share its name with another '…' declaration (a template does not overload)`

## What went wrong

A function without parameter types is a template: one body that is compiled once for every type it is called with. That cannot be combined with a typed function of the same name.

**How to fix it:** Rename one of the two, or give all of them parameter types.

## Example

<!-- doc-error -->
```km
fn twice(x: int): int
    return x * 2

fn twice(x)
    return x + x

void main()
    console.print(twice(3))
```

## Fixed

```km
fn twice(x)
    return x + x

void main()
    console.print(twice(3))
```
