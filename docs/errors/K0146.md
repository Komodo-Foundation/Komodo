# K0146: match not exhaustive

Message: `match on enum '…' is not exhaustive — missing: …`

## What went wrong

Under `--strict`, a `match` on an enum must name every variant or end with `else`, so adding a variant later cannot slip through unhandled.

**How to fix it:** Add a `case` for …, or an `else` branch.

## Example

<!-- doc-skip -->
Compile with `komodo --strict`.

```km
enum Color
    Red
    Green
    Blue

void main()
    let c = Color::Red
    match c
        case Color::Red
            print("red")
        case Color::Green
            print("green")
```

## Fixed

<!-- doc-skip -->
```km
enum Color
    Red
    Green
    Blue

void main()
    let c = Color::Red
    match c
        case Color::Red
            print("red")
        case Color::Green
            print("green")
        else
            print("blue")
```
