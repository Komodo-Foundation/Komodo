# K0073: pure function calls a procedure

Message: `a pure `fn` cannot call the void procedure '…'`

## What went wrong

A `fn` must not change anything visible, but a `void` procedure exists to cause effects. Calling one from a `fn` would hide those effects.

**How to fix it:** Make the caller `void` or `mut`, or make '…' a `fn`.

## Example

<!-- doc-error -->
```km
void log(msg: string)
    console.print(msg)

fn twice(n: int): int
    log("twice")
    return n * 2

void main()
    console.print(twice(2))
```

## Fixed

```km
void log(msg: string)
    console.print(msg)

void twice(n: int)
    log("twice")
    console.print(n * 2)

void main()
    twice(2)
```
