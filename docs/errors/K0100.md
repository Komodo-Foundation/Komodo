# K0100: export fn main

Message: ``export fn main` is not allowed…`

## What went wrong

`main` is the entry point of a Komodo program, and the C runtime already calls it. Exporting a function with that name would clash.

**How to fix it:** Export a function with a different name.

## Example

<!-- doc-skip -->
```km
export fn main(): int
    return 0
```

## Fixed

<!-- doc-skip -->
```km
export fn run(): int
    return 0
```
