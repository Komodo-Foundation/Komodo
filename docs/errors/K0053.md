# K0053: possibly null index target

Message: `value of type '…' is possibly null — narrow it before indexing`

## What went wrong

Indexing a nullable array or string would crash when the value is `null`.

**How to fix it:** Check `value != null` before indexing it.

## Example

<!-- doc-error -->
```km
fn find(k: int): [int]?
    if k > 0 then
        return [k]
    return null

void main()
    let xs = find(0)
    print(xs[0])
```

## Fixed

```km
fn find(k: int): [int]?
    if k > 0 then
        return [k]
    return null

void main()
    let xs = find(0)
    if xs != null then
        print(xs[0])
```
