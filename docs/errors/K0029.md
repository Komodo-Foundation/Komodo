# K0029: `in` right-hand side

Message: ``in` wants a string or an array on the right, got '…'`

## What went wrong

`in` searches inside a collection. Its right-hand side must be a string (substring test) or an array (element test).

**How to fix it:** Put an array or a string after `in`.

## Example

<!-- doc-error -->
```km
void main()
    let n = 5
    print(n in 42)
```

## Fixed

```km
void main()
    let n = 5
    print(n in [4, 5, 6])
```
