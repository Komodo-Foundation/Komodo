# K0022: incompatible extern argument

Message: `argument … to extern '…': '…' is not compatible with '…'`

## What went wrong

Arguments to a C function must match the C parameter's type, because the call passes the raw value across the C ABI.

**How to fix it:** Pass a value of type '…'.

## Example

<!-- doc-error -->
```km
extern fn takes_int(n: int): int

void main()
    print(takes_int("seven"))
```

## Fixed

```km
extern fn takes_int(n: int): int

void main()
    print(takes_int(7))
```
