# K0142: field named twice

Message: `field '…' named twice in pattern '…'`

## What went wrong

Each field can be matched once in a pattern.

**How to fix it:** Remove the duplicate.

## Example

<!-- doc-error -->
```km
struct P
    x: int

void main()
    let p = new P(1)
    match p
        case P(x: 1, x: 2)
            print(1)
        else
            print(2)
```

## Fixed

```km
struct P
    x: int

void main()
    let p = new P(1)
    match p
        case P(x: 1)
            print(1)
        else
            print(2)
```
