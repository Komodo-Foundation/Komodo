# K0040: too few arguments to a variadic function

Message: `'…' takes at least … argument(s), got …`

## What went wrong

A variadic function still needs all of its fixed parameters. Only the extra arguments after them are optional.

**How to fix it:** Pass at least … argument(s).

## Example

<!-- doc-skip -->
```km
extern fn printf(fmt: string, ...)

void main()
    printf()
```

## Fixed

<!-- doc-skip -->
```km
extern fn printf(fmt: string, ...)

void main()
    printf("hi\n")
```
