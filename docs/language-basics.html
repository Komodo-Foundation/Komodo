Language Basics

Syntax & Formatting

Komodo uses indentation-based blocks (like Python). Newlines are significant.

// Single-line comment
/* Multi-line comment */
/** Documentation comment */

Variables

Declare variables with let. By default they're reassignable; use be for immutable bindings:

let x = 10              // reassignable
let y be 20             // immutable
let z: int = 30         // explicit type
let w: float be 3.14    // immutable with type

All variables are block-scoped. Inner declarations shadow outer ones.

Primitive Types

Type Description Examples
int 64-bit signed integer 42, -100
uint 64-bit unsigned integer 42u
float 64-bit floating-point 3.14, 2.0f
bool Boolean value true, false
string UTF-8 string "hello"
char Single character 'a', '\n'

Fixed-width integers: i8, i16, i32, i64, u8, u16, u32, u64.

Arrays & Slices

Arrays are homogeneous fixed-size collections. Create them inline or empty:

let arr = [1, 2, 3]        // inferred as [int]
let empty: [int] = []       // empty array
let len = #arr              // array length

// Array access
print(arr[0])               // 1
arr[1] = 5                  // modify

Slices are array ranges:

let slice = arr[0 to 2]     // elements 0 and 1
let rest = arr[1 to #arr]   // from index 1 to end

Functions

Functions use fn for pure functions (no mutations), or void for procedures:

fn add(a: int, b: int): int
    return a + b

void greet(name: string)
    print("Hello, ", name)

fn sqrt(x: float): float
    return x.sqrt()         // method call

// With defaults
fn repeat(msg: string, times: int = 3): string
    // ...

Functions may have default parameter values. Return type follows :. Use bare return in void functions.

Macros

Compile-time macros are declared with be. Every use is replaced by a fresh lowering of the expression:

let BUFFER_SIZE be 1024
let VERSIONS be [1, 0, 0]

void main()
    // Each use of BUFFER_SIZE or VERSIONS re-evaluates the expression
    let buf = [0; BUFFER_SIZE]
    print(VERSIONS[0])

Macros are block-scoped and re-evaluated at each site. Keep macro bodies simple.

Control Flow

All blocks use indentation. No parentheses required:

// if / else
if x > 0
    print("positive")
else if x < 0
    print("negative")
else
    print("zero")

// while
while count < 10
    print(count)
    count = count + 1

// for
for i in 0 to 10
    print(i)

// break and continue
while true
    if flag
        break
    if skip
        continue

Type Casting

Use as to cast between types:

let x = 42 as float     // int to float
let y = 3.14 as int     // float to int (truncates)
let s = 65 as char      // int to char

Nullable Types

Add ? to make a type nullable:

let x: int? = null
let y: int? = 42

if x is int?
    print(x)

Use is to check and extract nullable values (see Advanced for more).
