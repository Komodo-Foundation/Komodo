Object-Oriented Programming

Structs

Structs are value types (flat C aggregates) with typed fields:

struct Point
    x: int
    y: int

struct Rectangle
    topleft: Point
    width: int
    height: int

Instantiate and access fields:

let p = Point(x: 10, y: 20)
print(p.x, p.y)

let r = Rectangle(topleft: p, width: 100, height: 200)

Structs with Methods

Add methods to structs. Use fn for pure methods, void for side effects:

struct Point
    x: int
    y: int

    fn distance(): float
        let dx = this.x as float
        let dy = this.y as float
        return (dx * dx + dy * dy).sqrt()

    void translate(dx: int, dy: int)
        this.x = this.x + dx
        this.y = this.y + dy

Call methods with dot notation:

let p = Point(x: 3, y: 4)
print(p.distance())      // 5.0
p.translate(1, 1)

Classes

Classes are reference types with single inheritance and virtual dispatch:

class Animal
    name: string
    age: int = 0

    void eat(food: string)
        print(this.name, " eats ", food)

class Dog : Animal
    breed: string = "Mixed"

    void bark()
        print(this.name, " barks!")

Subclasses inherit fields and methods. Use : to specify the parent class.

Field Defaults

Class and struct fields can have default values:

class Dog : Animal
    breed: string = "Mixed"
    tricks: int = 0

let d = Dog(name: "Buddy", age: 5)
print(d.breed)          // "Mixed" (default)
print(d.tricks)         // 0 (default)

Virtual Dispatch

Methods are dispatched virtually. When you call a method on a base-typed object, the runtime picks the right implementation:

class Shape
    void draw()
        print("Drawing a shape")

class Circle : Shape
    void draw()
        print("Drawing a circle")

class Square : Shape
    void draw()
        print("Drawing a square")

void main()
    let shapes: [Shape?] = [Circle(), Square()]
    for s in shapes
        if s is Shape
            s.draw()    // calls Circle::draw or Square::draw

Type Checking with is

Use is to check an object's runtime type:

let obj: Shape? = Circle()
if obj is Circle
    print("It's a circle")
else if obj is Square
    print("It's a square")

Abstract Classes

Mark a class abstract to prevent direct instantiation:

abstract class Shape
    fn area(): float

class Circle : Shape
    radius: float
    fn area(): float
        return 3.14159 * this.radius * this.radius

Inheritance Rules

  • Single inheritance only — a class has one parent
  • Subclasses inherit all fields and methods
  • Field order: parent fields first, then subclass fields
  • Methods can be overridden in subclasses
  • Structs do not support inheritance, only composition
