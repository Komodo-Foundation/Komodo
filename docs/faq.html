Frequently Asked Questions

What's the difference between .km and .kmm files?

.km files are programs (they must have void main()), while .kmm files are modules (libraries with no main). Both are compiled together.

Do I need to install anything special?

You need Python 3, the KomodoPy reference interpreter, NASM, and GCC. See Getting Started for setup instructions.

Is the compiler self-hosting yet?

Not yet. The compiler is written in Komodo and runs on the reference interpreter. It's almost ready to compile itself — a few language features are missing from the interpreter to allow full self-hosting.

Can I use multiple inheritance?

No, Komodo only supports single inheritance. Use composition (struct/class fields) if you need multiple types of behavior.

What happens if I don't provide a type annotation?

The compiler infers types from context. If it can't decide unambiguously, you'll get a compile error asking for an explicit annotation.

Can I call C code from Komodo?

Yes, use extern fn declarations. The compiler supports the full System V AMD64 ABI, so you can call any C function with proper signatures.

What's the performance like?

The x86-64 backend generates native code compiled by GCC, so performance is comparable to C. Stack-VM is slower but useful for testing and portability.

Can I modify structs after creation?

Yes, struct fields are mutable by default. Use a void or mut method to modify fields. For immutability, declare the struct binding as be instead of regular let.

How does method overriding work?

When you define a method in a subclass with the same name and signature as the parent, it overrides the parent's method. Dispatch is virtual by default.

What's the entry point for command-line args?

Define void main(args: [string]). The args array contains the command-line arguments (program name at index 0, user args starting at index 1).

Can I use generics with classes?

Classes themselves aren't generic, but you can write generic functions that work with any class or struct. Call-site monomorphization handles specialization.

How do I debug compilation errors?

The compiler reports errors with line and column numbers. Read the error message carefully — it will tell you what type or syntax issue was found. Check the Language Basics page for reference.

Can I write inline assembly?

Not directly, but you can use extern fn to call C functions that contain assembly. The x86 backend generates optimized assembly automatically.

What's the difference between fn and void?

fn declares a pure function that returns a value. void declares a procedure that has side effects and returns nothing. Methods can be either.

Where can I get help?

  • GitHub repository — source code and issue tracker
  • Read the Language Design document for deeper semantics
  • Check the examples/ directory for working programs
