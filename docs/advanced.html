Advanced Features

Generic Functions

Write implicit-type generic functions. The compiler monomorphizes at each call site:

fn first(arr: [T]): T
    return arr[0]

fn swap(a: [T], b: [T])
    let tmp = a[0]
    a[0] = b[0]
    b[0] = tmp

void main()
    let ints = [1, 2, 3]
    let floats = [1.0, 2.0, 3.0]

    print(first(ints))      // monomorphizes for [int]
    print(first(floats))    // monomorphizes for [float]

Type parameters are denoted by capital letters (T, K, etc.). Each call generates a specialized version.

Function Overloading

Free functions can be overloaded by parameter type or count. Resolution happens at compile time:

fn add(a: int, b: int): int
    return a + b

fn add(a: string, b: string): string
    return a + " " + b

fn add(a: int, b: int, c: int): int
    return a + b + c

void main()
    print(add(1, 2))            // calls int overload
    print(add("hello", "world")) // calls string overload
    print(add(1, 2, 3))         // calls 3-argument overload

When a base-typed argument matches multiple overloads, a runtime dispatch is emitted. Method overloading is not supported.

Runtime Type Dispatch

If multiple function overloads are equally valid at compile time, the compiler emits a runtime type check:

abstract class Animal
    void sound()

class Dog : Animal
    void sound()
        print("Woof")

class Cat : Animal
    void sound()
        print("Meow")

fn describe(a: Animal)
    print("Animal sound:")
    a.sound()

void main()
    let animals: [Animal?] = [Dog(), Cat()]
    for a in animals
        if a is Animal
            describe(a)  // runtime type check at call

Nullable Types & Type Checking

Make a type nullable with ?. Use is to safely extract the value:

fn parse_int(s: string): int?
    // returns int? (could be null)
    return null    // or a parsed value

void main()
    let x = parse_int("42")
    if x is int
        print("Got integer: ", x)  // x is int here
    else
        print("Parse failed")

Inside the if branch after x is int, the type is narrowed to int.

Method Mutation with mut

Mark a method mut if it modifies the receiver's state:

struct Counter
    value: int = 0

    fn get(): int
        return this.value

    mut increment()
        this.value = this.value + 1

void main()
    let c = Counter()
    print(c.get())      // 0
    c.increment()
    print(c.get())      // 1

The mut keyword clarifies which methods have side effects.

Extern Functions

Call C functions directly with full System V AMD64 ABI support:

extern fn printf(format: string, ...): int
extern fn malloc(size: uint): string?
extern fn free(ptr: string?)

void main()
    printf("Hello, %s!\n", "Komodo")
    let mem = malloc(1024u)
    if mem is string
        free(mem)

Variadic functions are supported. The compiler handles register allocation and calling convention.

Array Slices

Extract array ranges with the slice syntax arr[start to end]:

let arr = [10, 20, 30, 40, 50]
let slice1 = arr[0 to 3]    // [10, 20, 30]
let slice2 = arr[2 to #arr] // [30, 40, 50]
let slice3 = arr[1 to 4]    // [20, 30, 40]

Slices are themselves arrays and can be passed to functions expecting arrays.

Type Inference

The compiler infers types from context. Explicit annotations are only needed when the compiler can't decide:

let x = 42              // inferred as int
let y = 3.14            // inferred as float
let z = [1, 2, 3]       // inferred as [int]

// Ambiguous — must annotate
let empty: [int] = []   // explicit type needed
