Komodo

A self-hosting compiler for the Komodo language

Komodo compiles to native x86-64 or a stack-VM bytecode. The compiler itself is written in Komodo and runs on the reference interpreter until it achieves self-hosting.

Get Started View on GitHub

Language Features

🔧 Native Compilation

Compiles to x86-64 assembly or stack-VM bytecode. Direct x86 target for full performance.

📦 Object-Oriented

Structs, classes with single inheritance, virtual dispatch, and method definitions.

🔤 Generics & Overloading

Implicit-type generic functions with call-site monomorphization and free-function overloading.

🎯 Type Safety

Strong static typing with type inference, nullable types, and runtime type checks.

📚 Modules

Multi-file modules with explicit imports and namespace management.

🔗 C FFI

Full System V AMD64 ABI support for calling C code directly.

Quick Example

import console

struct Point
    x: int
    y: int

fn distance(p: Point): float
    let dx = p.x as float
    let dy = p.y as float
    return (dx * dx + dy * dy).sqrt()

void main()
    let p = Point(x: 3, y: 4)
    print("Distance: ", distance(p))

Getting Started

Komodo requires Python 3, the reference interpreter, NASM, and GCC. Set up the environment and build your first program:

export KOMODO_MAIN="/path/to/KomodoPy/main.py"
./build.sh examples/features_demo.km
